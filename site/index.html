The problem

Autonomous agents are powerful.
Unsupervised, they're risky.

You kick off an AI coding job, step away, and come back to find it deleted a table, committed a breaking change, or burned through your budget while you weren't watching. Current tools either chain you to your desk or give you no visibility at all once the job is running.

Iron Rain solves the supervision problem: it brings the entire agent loop to your pocket with real controls — not just a notification that something already went wrong.

Immediate control

Pause, redirect, or kill a runaway agent before it compounds the mistake — from anywhere.

Explicit approval

Every sensitive tool call — shell commands, file writes, git ops — requires your sign-off.

Spending guardrails

Set a dollar budget. The heartbeat loop stops the agent before it overspends.

Core capabilities

Everything you need to run agents off-desk.

01

Live session control

Watch agent output stream in real time on your iPhone. Pause a session mid-thought, redirect it with a new instruction, or kill it outright — all without touching your Mac. Push notifications alert you when a session finishes, errors, or needs input.

02

Approve from your lock screen

When an agent needs to run a shell command, write a file, or push a commit, a Live Activity appears on your lock screen. Tap Allow or Deny — no unlock needed. The agent waits, then continues from exactly where it stopped.

03

Review diffs. Comment to steer.

Open the agent's git diff in a native diff renderer on your phone. Leave a comment on any line — your comment becomes a prompt the agent acts on immediately. Correct a mistake or redirect an approach without opening a terminal or pulling up your laptop.

04

Autonomous heartbeat + cost budgets

Let an agent run a long job completely unattended. The heartbeat loop keeps it going until the task is done, with configurable nudge caps and a dollar budget so it never runs away. Before context fills, the agent checkpoints its own progress and hands off cleanly to the next pass — no lost work.

05

Cross-repo workspaces

Tackle a task that spans multiple repositories in one coordinated job. Each repo gets its own isolated git worktree and branch. Per-project setup hooks copy your .env, install deps, and assign a port. Ship the work as a coordinated set of PRs — one task, multiple repos, one flow.

06

Plan mode, cost meters & live to-do

Switch an agent into plan mode: it proposes what it intends to do, you approve the plan before it touches a single file. Live cost and token meters let you track spend in real time. A live to-do list shows which tasks are in flight and which are done — so you're never guessing what the agent is actually up to.

Built-in IDE

Inspect and edit code without leaving the app.

Iron Rain ships a native code editor with full LSP support — diagnostics, hover documentation, and go-to-definition, powered by the same language servers running on your Mac. A native diff renderer lets you review changes with the precision of a desktop IDE.

Most mobile agent tools give you a log tail and a text field. Iron Rain gives you a real editor, connected to the real language server, showing real compiler errors in real time. It's the part of the stack nobody else in the mobile-agent space has built.

  • Inline diagnostics (errors & warnings) from the language server
  • Hover documentation & go-to-definition across files
  • Native diff renderer with syntax highlighting
  • Inline image preview for agent-generated assets
  • sourcekit-lsp  ·  pyright  ·  rust-analyzer  ·  clangd

Security & trust

Your code never leaves your Mac.

Iron Rain is designed to be private by construction. We cannot see your code, your prompts, or your keys — because none of it ever reaches our servers.

End-to-end encrypted

The iOS app and Mac daemon negotiate encryption keys during pairing. All session data is encrypted in transit — Iron Rain's relay, if used, sees only opaque ciphertext.

Runs on your hardware

The coding agent runs on your Mac, in your environment, using your filesystem. No cloud sandbox, no third-party compute ever sees your source code.

Your subscription, your keys

claude-code runs on your existing Claude subscription. API keys, if needed for headless use, live on your Mac only — never on our servers.

No analytics, no tracking

Iron Rain has no analytics, no ads, and no third-party trackers. Read the full privacy policy — it's short and plain-English.

Get started

Up and running in two steps.

No configuration files, no dependency wrangling. The installer handles everything.

1

Install on your Mac

One command installs the Iron Rain Mac app and daemon, then launches the app. It auto-detects opencode, claude-code, and pi, sets up the integration on first run, and displays a pairing QR code to scan from your phone.

curl -fsSL https://howlerops.github.io/oculus/install.sh | sh

Headless or Linux? The same command installs just the daemon (~/.oculus/oculusd.log). Prefer source? cd daemon && go run . serve --secret <your-secret>

2

Join the iOS TestFlight

Join the TestFlight beta, install the Iron Rain iOS app, then scan the QR code displayed by the Mac app to pair your devices. Everything after that is automatic.
